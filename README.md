# Discovering Databases: An Easy Start for Beginners

Welcome to “Discovering Databases: An Easy Start for Beginners.”
This project is designed to introduce you to the foundational concepts and practical skills necessary to work with databases effectively.

This repo will walk me (and you) through everything from understanding what a database is to executing your first SQL commands.

## What I’m Learning

- Introduction to Databases — what databases are, why they’re important, and how they’re used.
- Types of Databases — relational, non-relational, and their key differences.
- Getting Started with SQL — the language of databases.
- CRUD Operations — learn how to:
    Create tables and records
    Read (retrieve) data
    Update existing entries
    Delete records safely
- Hands-On Practice — build tables, run queries, and manipulate real data.
- Advanced SQL Techniques — filtering, sorting, and joining tables to get deeper insights.

## Tools & Technologies

- MySQL — main database management system.
- MySQL Shell / MySQL Workbench — for running SQL commands.
- Python + MySQL Connector — to connect and interact with your database programmatically.
- VS Code — development environment.
